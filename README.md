# 郑慧茹个人简历网站

基于 React + Vite 构建的响应式个人简历网站。

## 直接预览

双击仓库根目录的 `index.html`，或在浏览器中打开：

```text
file:///E:/cc%20data/github/my-first-site/index.html
```

该文件已内嵌 React、页面样式和人物照片，不需要启动本地服务器。

## 开发模式

```bash
pnpm install
pnpm dev
```

开发入口为 `http://localhost:5173/app.html`。

## 更新直接预览文件

```bash
pnpm build
```

构建完成后会自动更新根目录的 `index.html`。
